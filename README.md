## 🚀 Featured Projects

- **[vortex-dispatch](https://github.com/tzone85/vortex-dispatch)** — Hand off a coding requirement and watch AI agents (Claude Code, Codex, Gemini CLI) ship merged PRs. Decomposes work into atomic stories, runs them in parallel git worktrees with per-story ephemeral Postgres, reviews and tests every change, escalates failures through 5 tiers, and merges what passes. Event-sourced, Go.
- **[px-dispatch](https://github.com/tzone85/px-dispatch)** — Clean-slate successor to vortex-dispatch with first-class cost budgets, session-health watchdogs, decomposed pipeline retry policies, and OSS-ready packaging (Homebrew tap, Docker, signed GitHub Releases).
- **[themis](https://github.com/tzone85/themis)** — Compliance gateway for AI-generated code. Signed AIBOMs per PR, tamper-evident ledger, policy-as-code gates that block changes violating your rules before they merge.
- **[nexus-dispatch](https://github.com/tzone85/nexus-dispatch)** — Offline-first AI dev team in a CLI. Local LLMs via Ollama. No API keys, no rate limits.
- **[nhanga](https://github.com/tzone85/nhanga)** — PWA for learning Shona through music. One song a week, Sunday quiz.
- **[sa-fintech-skills](https://github.com/tzone85/sa-fintech-skills)** — Multi-runtime AI-agent skill pack for South African fintech APIs (Paystack, PayFast, POPIA, SARS).
